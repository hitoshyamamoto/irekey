# schemas

This directory will hold the published JSON Schemas of the files irekey
reads, such as the device file, the component manifest and the release
set, so that editors and other tools can validate them. Each schema is
identified as `irekey/<kind>/v<N>`.

The files here are generated copies of the schemas embedded in
`internal/schema`; do not edit them by hand.
`docs/schema-versions.txt` lists every schema and version the current
build reads.
