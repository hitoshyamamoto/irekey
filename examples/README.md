# examples

This directory will hold a complete, fictional deployment repository
(`deployment-repo/`, with CI files for GitHub and GitLab that run
`irekey ci`) and a sample component manifest (`component/.irekey/`), to
show the file formats with realistic content.

Everything in them is fictional: the customers are acme, globex and
initech, domains use example.com, IP addresses come from the documentation
ranges (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24 and 2001:db8::/32)
and MAC addresses are locally administered. As data separation requires,
no customer data ever goes into this public repository.

Nothing is here yet; see ROADMAP.md.
