# irekey

irekey manages the same software running on many offline embedded Linux
computers, where every customer needs small local differences, and delivers
changes over SSH with automatic rollback.

**Status: not usable yet.** The repository is being set up. There is no
release; the only commands so far are `irekey version` and
`irekey-exec capabilities`. The full specification is in
[docs/spec/masterprompt.md](docs/spec/masterprompt.md).
