# Domains that may appear in documentation, examples, lab files, schemas
# and test data (checked by scripts/check-realdata.sh).
#
# The reserved names are always allowed and need no entry: example.com,
# example.net, example.org and their subdomains, names ending in .example,
# .test, .invalid or .localhost, and localhost.
#
# Only tools, modules, standards and hosting services that irekey uses or
# cites belong here; never a customer, site or employer domain. An entry
# also allows its subdomains (github.com allows docs.github.com and
# users.noreply.github.com), so list a single site of a shared hosting
# domain (adr.github.io), never the hosting domain itself (github.io).
# Intranet names (.local, .lan, .corp, .internal, .intranet, .home.arpa,
# .localdomain) are always reported unless the whole name is listed.
#
# Format: one domain per line, followed by a comment saying why it is
# allowed. Blank lines and full-line comments are allowed.
#
#   <domain> # <why>
